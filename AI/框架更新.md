# 框架更新

框架更新是用户主动触发的独立操作，不属于初始化、查询、记录或日常维护流程。

- 没有用户明确要求时，不检查模板版本，不提示或执行升级。
- 用户拒绝升级时，继续按当前个人仓库版本正常使用。
- 更新前展示版本差异、框架路径和受保护目录，并等待确认。
- 更新只允许操作框架文件，必须保留 `Knowledge/`、`Projects/`、`Daily/`、`Inbox/`、`Attachments/`、`Archive/`、`AI/LOCAL.md`、`AI/写入日志.md`、`AI/写入日志/`、`.kb-role` 和其他用户文件。
- Codex 完成框架复制后，先用更新后的个人仓库安装脚本重新安装全局 `work-knowledge` Skill，再运行验证；其他 Agent 跳过 Codex Skill 安装。
- 提交和推送分别需要再次确认。

Windows 使用 `scripts/update-framework.ps1`；macOS/Linux 使用 `scripts/update-framework.sh`。如当前旧版本没有更新器，用户可以明确要求读取模板仓库公开的 `UPDATE.md`。
