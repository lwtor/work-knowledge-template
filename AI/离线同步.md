# 离线加密增量同步

公司电脑不能 push 时，使用 `scripts/kb-transfer.py` 将个人数据加密后通过手机或 U 盘带回家。

## 首次准备

需要在 macOS 和 Windows 上各安装：

- Python 3；
- Git；
- `age` 加密工具，并确保 `age` 在 PATH 中。

检查：

```bash
python scripts/kb-transfer.py doctor
```

## 公司电脑导出

```bash
python scripts/kb-transfer.py export --out /path/to/phone/Work-Knowledge-增量.age
```

Windows 示例：

```powershell
py scripts\kb-transfer.py export --out E:\Work-Knowledge-增量.age
```

脚本只处理 `Knowledge/`、`Projects/`、`Daily/`、`Inbox/` 和 `Attachments/`，只输出相对于上次导出的新增、修改和删除内容。输入加密密码时不要把密码写进命令行。

## 家里电脑导入

```bash
python scripts/kb-transfer.py import \
  --package /path/to/Work-Knowledge-增量.age \
  --vault /path/to/Work-Knowledge
```

Windows 示例：

```powershell
py scripts\kb-transfer.py import `
  --package E:\Work-Knowledge-增量.age `
  --vault C:\Users\你的用户名\Work-Knowledge
```

导入前会检查两台电脑的个人数据基础版本。如果检测到双方都有不同修改，脚本会停止，不会覆盖文件。导入成功后再执行 `git diff`、`git commit` 和 `git push`。

## 安全边界

- `.age` 是加密包，不应把密码和加密包放在一起传输；
- 手机只作为传输介质，不建议长期保存明文知识库；
- 公司政策禁止把资料带出时，不得使用本流程；
- 模板、AI 规则和脚本不通过离线包传输，框架更新仍使用模板仓库；
- 不要用网盘明文同步个人工作资料。
