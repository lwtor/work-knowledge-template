·# AI 使用示例

## 把对话整理成可复用知识

```text
把刚才关于 [主题] 的内容整理到知识库。
请提炼问题、结论、适用场景、步骤、注意事项和来源。
先检查是否已有类似笔记，给我看拟新增或修改的文件，等我确认后再写入。
```

## 把资料记录到项目

```text
把这个链接记录到 [项目名称]，类型是 [需求/设计/测试/接口]。
请补充标题、链接、用途说明和来源，先给我预览。
```

## 查询历史知识

```text
请搜索我的本地知识库，查找关于 [关键词] 的记录。
只使用找到的本地内容，列出关键结论、适用条件和参考文件；找不到时明确告诉我。
```

## 查看项目状态

```text
请读取 [项目名称] 的项目总览、待办、开发记录和资料索引，
总结当前进展、未完成事项、重要文档和已知问题，并引用文件路径。
```

## 记录临时想法

```text
把下面内容先记录到 Inbox，不要自行扩展或当成已确认事实：
[内容]
```
