# Maintain project knowledge

For a new project, propose a directory under `Projects/`, create its entry from `Templates/项目总览.md`, and add links, tasks, or development records only as needed. Show proposed files and wait for confirmation before writing.

For project questions, read the overview, tasks, development records, and link index before answering.

Official requirement, code, issue, and approval systems remain authoritative. The knowledge base stores personal context and indexes; it does not replace those systems.
