# Save and organize knowledge

1. Read `AI/AI-GUIDE.md`.
2. Extract the problem, context, conclusions, steps, applicability, cautions, and sources from content visible in the current Codex task.
3. Search indexes, aliases, tags, `Knowledge/`, `Projects/`, and `Inbox/` for related material.
4. Decide whether to update an existing note, create a note, or stage it in `Inbox/`.
5. Show the proposed files, paths, and content summary.
6. Wait for user confirmation before writing.
7. After writing, update `updated` and append the current month under `AI/写入日志/`; update `last_verified` only when actually revalidated.
8. Rebuild indexes when useful; do not hand-maintain derived index entries.
9. Report created, updated, linked, omitted, and unresolved content.

Do not present inference as fact, silently overwrite or merge notes, invent sources, or claim content was saved unless the files were actually written.
