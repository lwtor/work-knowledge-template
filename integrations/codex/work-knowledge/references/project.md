# Maintain project knowledge

Resolve the active layout first. For a new project, propose a directory under the resolved project root and create its entry from the matching project template. In layout 2, keep the project homepage at `Vault/02-项目/<项目名>/项目主页.md`, and separate reusable project knowledge, requirements, and project-specific problems into `项目知识/`, `需求/`, and `项目问题/`. Show proposed files, then use the numbered required-confirmation block; support its number or copyable reply `确认按上述预览写入知识库，不提交、不推送。`. Do not write before confirmation.

For project questions, read the overview, tasks, development records, and link index before answering.

Official requirement, code, issue, and approval systems remain authoritative. The knowledge base stores personal context and indexes; it does not replace those systems.
